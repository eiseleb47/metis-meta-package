## Purpose

This is the **metis-meta-package**: a `uv`-based meta-installer and ScopeSim instrument package collection for the METIS Pipeline ESO stack. It installs `pycpl`, `pyesorex`, `edps`, `adari_core`, `scopesim`, and `scopesim_templates` from custom indexes (ivh's pycpl index + ESO FTP index).

## Setup

```bash
./bootstrap.sh
```

Bootstrap:
1. Clones `METIS_Pipeline` and `METIS_Simulations` into `$HOME/`
2. Runs `uv sync` to install all dependencies into a managed venv
3. Starts EDPS once to generate `~/.edps/application.properties`, then patches it: `port=4444`, `workflow_dir=~/METIS_Pipeline/metisp/workflows`, `esorex_path=pyesorex`
4. Writes `.env` (gitignored) with `PYTHONPATH`, `PYCPL_RECIPE_DIR`, `PYESOREX_PLUGIN_DIR`

## Running Commands

All commands must be prefixed with `uv run --env-file .env` from this directory:

```bash
uv run --env-file .env pyesorex --recipes
uv run --env-file .env edps -P 4444 -lw        # list workflows / confirm server running
uv run --env-file .env python my_script.py
```

The `.env` file is auto-generated by `bootstrap.sh` and is gitignored. If it's missing, re-run bootstrap.

## Repository Layout

```
metis-meta-package/
├── bootstrap.sh          # Full installation script (interactive)
├── pyproject.toml        # uv/pip meta-package with extra-index-url for pycpl and ESO libs
└── .env                  # Generated at bootstrap time (gitignored); required for uv run
```

## EDPS Configuration Note

EDPS runs on port **4444** (not the default 5000). The `application.properties` file at `~/.edps/application.properties` is patched by bootstrap. If EDPS commands fail with connection errors, verify this file has `port=4444`.
